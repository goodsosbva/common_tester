## 실행 중 수정한 오류

첫 실행에서 모델이 정책 검색 도구에 `top_k=10`을 전달했다. 서버의 허용 범위는 1~5라 Pydantic `ValidationError`가 발생했다. [도구 명세](../../api/app/generator.py)에 `minimum: 1`, `maximum: 5`를 추가해 모델에 같은 범위를 알렸다. 새 실행에서 계획 생성과 브라우저 실행이 완료됐다.

## 결과의 범위

- 20/20은 이 실행계획의 assertion이 데모 화면에서 통과했다는 뜻이다. 다른 사이트에 대한 성공률이나 생성 계획의 전반적인 품질 점수가 아니다.
- 정책 근거 ID와 버전은 서버가 검사한다. 기대값이 정책 문장의 의미와 맞는지는 계획 검토 과정에서 확인해야 한다.
- 전체 실행 캡처는 로컬 데이터로 보관한다. 저장소에는 결과 확인용 예시 PNG 한 장만 포함한다.
