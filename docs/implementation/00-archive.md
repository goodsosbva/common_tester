# 0단계 기존 코드 보관

완료일: 2026-10-27

## 목적

루트의 2.0.0 구현과 실행 데이터를 보관하고, 루트에 2.0.1을 새로 구축할 공간을 확보한다. 기존 1.0.0 코드는 덮어쓰지 않는다.

## 처리

- 루트의 api, web, docs, examples, README, 2.0.0 기획안, .env.example, .local, .venv를 1.0.0/2.0.0-snapshot/으로 옮겼다.
- 기존 1.0.0/의 파일은 그대로 두었다.
- 루트 .env는 새 버전에서 사용할 설정이라 옮기거나 출력하지 않았다.
- 루트 .git, .gitignore, 2.0.1 기획 문서는 유지했다.
- 이동 중 사용 중인 Common Tester API, Vite, 예제 서버를 종료했다. VS Code는 종료하지 않았다.

## 확인

| 항목 | 보관 파일 수 |
| --- | ---: |
| api | 17 |
| web | 516 |
| docs | 3 |
| examples | 8 |
| .local | 69 |
| .venv | 8074 |
| 루트의 개별 파일 4개 | 4 |

web은 처음 확인할 때 514개였고, 실행 중이던 Vite가 만든 캐시 파일 2개가 보관 과정에 추가됐다. 기존 소스 파일은 모두 스냅샷에 있다. 1.0.0/README.md도 그대로 확인했다.

파일별 보관 수량과 크기는 1.0.0/2.0.0-snapshot/_archive-manifest.json에 기록했다. 현재 루트에는 2.0.1 기획 문서, .env, .git, .gitignore, 1.0.0만 남았다.

다음 단계는 루트에 새 API, 웹 화면, Playwright 실행 환경과 제품/버전 문서 폴더를 만드는 것이다.
