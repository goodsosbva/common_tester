이 폴더의 코드는 실행 증거 사본이다. 실제 생성본과 실행별 전체 자료는 로컬 `.local/runs/`에 남아 있다. 스크린샷은 해당 execution 폴더의 원본을 복사했다. 키, 인증 정보와 원격 페이지 전체 HTML은 포함하지 않았다.

## 검증 범위

주소 검증, 실제 화면 자료 전달, 일반 문서 ID와 기존 PDF ID 보존, 전부 미지원인 경우의 미실행 판정, 명세 검증과 제한 재시도, 결과 집계, 기존 두 작업의 파일 격리, React 빌드를 확인했다. 브라우저에서 실제 결과와 PNG 표시, 미지원 목록, 모바일 표시를 확인했다. 모델 전체 생성은 이 PR 정리 과정에서 중복 호출하지 않았다.
