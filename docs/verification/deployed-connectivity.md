배포 URL 연결 점검 계획. 대상 http://goodsosbva1.dothome.co.kr/. 실제 공개 화면에서 관찰한 제목과 내부 이동만 확인한다. 제품 기획서를 대신하는 문서가 아니며 회원가입, 주문, 메시지 전송은 점검하지 않는다.

CONNECT_001: 페이지 제목은 권현성 — Frontend Developer이고, 주 제목 권현성.이 표시된다.

CONNECT_002: 주요 메뉴의 작업 링크는 #work를 가리키며 클릭하면 고친 문제 세 가지 영역으로 이동한다.

CONNECT_003: 주요 메뉴의 경력 링크는 #career를 가리키며 클릭하면 경력 영역으로 이동한다.

CONNECT_004: 주요 메뉴의 기술 링크는 #skills를 가리키며 클릭하면 기술 스택 영역으로 이동한다.

CONNECT_005: 주요 메뉴의 연락 링크는 #contact를 가리키며 클릭하면 함께 일할 이야기가 있다면 연락 주세요. 영역으로 이동한다. 메일 링크는 클릭하지 않는다.

CONNECT_006: 본문으로 바로가기 링크는 #main을 가리키고 해당 id를 가진 본문이 존재한다. 클릭이나 Tab 키 접근으로 내부 본문 이동을 확인한다.
