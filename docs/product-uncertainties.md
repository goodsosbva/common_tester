# 제품 판정 미확정 항목

이 문서는 PDF 표를 읽으며 확인한 빈칸과 충돌을 기록한 검토 메모다. 새로운 제품 정책이 아니다. 테스트를 만들 때 PDF에 없는 값을 채워 넣지 않는다.

회원 | BE_USER_001: 닉네임 '15자'가 정확히 15자인지 최대 15자인지 미확정. 닉네임/이메일 중복 결과 문구와 인증 코드 유효 시간도 미확정.

회원 | BE_USER_004~006: 잘못된 로그인 정보나 소셜 로그인 실패의 화면 결과, 비밀번호 찾기 인증 코드의 유효 시간은 미확정.

상품 | BE_PRODUCT_001: 정렬 조건이 첫 문장과 상세 항목에서 다르게 열거된다. 어떤 정렬을 기본 제공하는지, 동률 처리 기준은 미확정.

상품 | BE_PRODUCT_010~012: 쿠폰 할인 금액의 반올림 방식과 쿠폰 복원 완료 화면 문구는 미확정.

장바구니 | BE_PRODUCT_005~007: 허용 수량의 최소/최대와 재고 초과 처리 문구는 원본에 없어 미확정.

주문 | BE_PRODUCT_013~018: 배송비 계산, 카드사 결제 성공/실패 응답, 주문 취소와 환불 승인 단계의 화면 결과는 미확정. BE_PRODUCT_017의 '주문 후 7일 이내'에서 시각 경계는 미확정.

리뷰 | BE_PRODUCT_019~021: 별점 범위, 리뷰 길이, 사진 크기/개수, 수정/삭제 완료 문구는 미확정.

커뮤니티 | BE_COMMUNITY_001~009: 제목/본문 길이, 첨부파일 제한, 좋아요/싫어요 재클릭 처리, 권한 거부 문구는 미확정.

추천 | PDF 6쪽 표 1행과 2행에 BE_RECOMMEND_001이 중복된다. 두 행은 각각 위시리스트와 장바구니 상위 추천인데 둘 다 상세에는 조회수 상위 8개라고 적혀 있어 실제 순위 기준이 미확정. BE_MAIN_002와 BE_RECOMMEND_003~006의 점수/동률 처리도 미확정.

알림 | BE_ALERT_001~004: '실시간'의 허용 지연, 정확한 제목/본문 문구, 읽음 처리/재발송 규칙은 미확정.

관리자 | BE_ADMIN_001~014: 가격/재고의 허용 최솟값, BE_ADMIN_011 선착순 쿠폰의 동시 요청 처리 순서, 비관리자 접근 거부 문구는 미확정.

메인과 고도화 | BE_MAIN_001의 추천 노출 순서, BE_REPAIR_001~002와 011~012의 배정 가능 조건/매입 가격 산정 방식은 미확정.
