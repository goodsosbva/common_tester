# 주문 등록 정책 v1
## 주문명 입력 정책
주문명은 필수 입력 항목입니다. 주문명은 최대 20자까지 허용합니다. 21자 이상이면 저장하지 않고 '주문명은 20자 이하여야 합니다.'를 표시합니다.

## 주문 수량 정책
주문 수량은 1부터 99까지의 정수만 허용합니다. 0, 음수, 소수는 저장할 수 없습니다.

재고 수량을 초과하면 주문을 저장하지 않고 재고 부족 메시지를 표시합니다.

## 주문 금액 정책
요청 금액은 0원 이상이어야 합니다. 음수 금액은 저장할 수 없습니다. 원화 금액은 소수점 없이 정수로 입력합니다.

## 주문 메모 정책
주문 메모는 선택 입력 항목입니다. 메모를 입력할 경우 최대 200자까지 저장할 수 있습니다.
