# 포트폴리오 공개 화면 연결 점검

이 문서는 사용자가 지정한 http://goodsosbva1.dothome.co.kr/ 공개 화면에서 확인한 제목과 내부 이동을 점검하기 위해 작성했다. 원래 제품 기획서를 대체하지 않으며 경력 내용의 진위, 회원가입, 주문, 메일 전송은 검사하지 않는다. 실패하거나 금지돼야 할 입력 기준은 제공되지 않았으므로 추측하지 않는다.

## 공개 화면

CONNECT_001 | 페이지 제목과 주 제목 | 첫 화면의 브라우저 제목은 권현성 — Frontend Developer이며, 주 제목 권현성.이 표시된다.

CONNECT_002 | 작업 메뉴 이동 | 첫 화면의 주요 메뉴 작업 링크는 #work를 가리키고 누르면 고친 문제 세 가지 영역으로 이동한다.

CONNECT_003 | 경력 메뉴 이동 | 첫 화면의 주요 메뉴 경력 링크는 #career를 가리키고 누르면 경력 영역으로 이동한다.

CONNECT_004 | 기술 메뉴 이동 | 첫 화면의 주요 메뉴 기술 링크는 #skills를 가리키고 누르면 기술 스택 영역으로 이동한다.

CONNECT_005 | 연락 메뉴 이동 | 첫 화면의 주요 메뉴 연락 링크는 #contact를 가리키고 누르면 함께 일할 이야기가 있다면 연락 주세요. 영역으로 이동한다. 메일 링크는 누르지 않는다.

CONNECT_006 | 본문 바로가기 | 첫 화면의 본문으로 바로가기 링크는 #main을 가리키고 해당 id를 가진 본문이 존재한다. 초기 화면이 표시된 뒤 키보드로 링크에 접근할 수 있다.
